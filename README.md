# ЛюдиИриски — React UI-компоненты 

Базовая структура интерфейса мобильного приложения мониторинга нарушений охраны труда с применением ИИ.

## Требования
- Node.js 18+
- npm

## Запуск
```bash
git clone <ссылка-на-репозиторий>
cd ohrana-app
npm install
npm run dev
```
Открыть http://localhost:5173

## Компоненты (src/components)
Button, InputField, VoiceButton, ViolationCard, BottomNav, NotificationCard.

## Технологии
React, Vite, PropTypes, CSS Modules.
